This repository is dedicated to Kubernetes (k8s) experiments and contains the following folders and their respective contents:

It is designed to help developers and operators understand and experiment with Kubernetes features, networking, and configurations.

## Folder Structure

### `/networking`
- Contains experiments and configurations related to Kubernetes networking.
- To include examples for service meshes, ingress controllers, and network policies.

## Getting Started

1. Clone the repository:
  ```bash
  git clone <repository-url>
  ```
2. Navigate to the project directory:
  ```bash
  cd k8s-labs
  ```
3. Go into any folder of your choice.
